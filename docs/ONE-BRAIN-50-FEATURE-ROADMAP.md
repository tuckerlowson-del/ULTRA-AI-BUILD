# ONE BRAIN — 50-feature expansion backlog

This is the next-build backlog, not a claim that every item is already implemented. Features should ship only when they work, persist correctly, and pass tests.

## Chat and conversation workflow
1. Rename conversations.
2. Archive conversations without deleting them.
3. Restore archived conversations.
4. Branch a conversation from any message.
5. Edit and resend a previous user message.
6. Regenerate the latest assistant response.
7. Add message reactions and bookmarks.
8. Search inside the open conversation.
9. Export one chat or the full chat library.
10. Import a previously exported chat.

17. Add a model response/latency test.
18. Add provider health and outage status.
19. Add configurable fallback models.
20. Add an automatic free-model-only filter.

## Delivery rule

Each feature must be marked **implemented**, **tested**, or **planned** separately. A visible button or placeholder does not count as a working feature.
